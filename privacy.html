Privacy policy

Dell assistant · last updated 8 November 2026

Dell assistant is a personal tool used only by its owner, on the owner's own home server. It accesses only the owner's own Google account, and only to do what the owner asks.

Data it accesses

With the owner's permission, it can read and change the owner's Gmail, Google Calendar, Google Drive and Google Tasks through Google's official APIs.

How the data is used

  • Only to answer the owner's own requests (for example, "what is on my calendar this week?").
  • To produce an answer, the relevant part of a request may be sent to the AI model providers the owner has chosen (currently Google Gemini and OpenRouter). Nothing else is sent to them.
  • It is never sold, never used for advertising, and never shared with anyone else.

Storage and security

Sign-in tokens are stored encrypted on the owner's home server, which is reachable only by the owner over a private network. Google data is processed there and is not copied to any other service.

Google API Services User Data Policy

Dell assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove access at any time at myaccount.google.com/permissions.
